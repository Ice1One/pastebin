## 🏗️ Stack

| Layer | Technology |
|-------|-----------|
| 🐍 Backend | Python / FastAPI |
| 🗄️ Database | SQLite |
| 🌐 Reverse Proxy | nginx |
| 🐳 Container | Docker + Docker Compose |
| ⚙️ CI/CD | GitHub Actions |
| ☁️ Hosting | Render (Free tier) |
| 🏗️ IaC | Terraform |
| ☸️ Orchestration | Kubernetes (minikube) |
| 📊 Monitoring | Prometheus + Grafana |
